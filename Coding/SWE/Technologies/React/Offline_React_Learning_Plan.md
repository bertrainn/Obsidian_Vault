# Offline React Learning Plan for Flights & Layovers

## 🛫 Pre-Flight Preparation Checklist

### Download Essential Resources (Do this before your flight!)

#### 📚 Documentation & Guides
- [ ] Download React official docs as PDF or use browser's "Save for offline reading"
- [ ] Download React DevTools documentation
- [ ] Save MDN JavaScript references offline
- [ ] Download React Router documentation
- [ ] Save Redux Toolkit documentation

#### 🎥 Video Content
- [ ] Download Scrimba React course for offline viewing
- [ ] Download specific YouTube playlists:
  - Net Ninja React Tutorial (download entire playlist)
  - Traversy Media React Crash Course
  - FreeCodeCamp React Course
- [ ] Use YouTube Premium or video downloaders to save content

#### 🛠️ Development Environment
- [ ] Install Node.js and npm on your laptop
- [ ] Install VS Code with essential extensions:
  - ES7+ React/Redux/React-Native snippets
  - Prettier
  - Bracket Pair Colorizer
  - Auto Rename Tag
- [ ] Pre-install Create React App globally: `npm install -g create-react-app`
- [ ] Pre-install Vite globally: `npm create vite@latest`
- [ ] Download React DevTools browser extension

#### 📱 Mobile Learning Apps
- [ ] Download SoloLearn React course
- [ ] Download Grasshopper app
- [ ] Download Mimo for JavaScript review
- [ ] Save coding challenges to phone notes

## 🔧 Technical Setup for Offline Learning

### Development Environment
```bash
# Pre-install these globally before flight
npm install -g create-react-app
npm install -g serve
npm install -g json-server

# Useful offline packages to pre-install
npm install -g nodemon
npm install -g prettier
npm install -g eslint
```

### Local Development Server
```bash
# For serving static files
npx serve -s build -p 3000

# For mock API data
npx json-server --watch db.json --port 3001
```

### Offline Documentation
- Save React docs as single HTML file
- Use browser's reading mode for clean offline access
- Create quick reference cards in notes app

## 💡 Pro Tips for Airplane Coding

1. **Battery Management:**
   - Bring portable charger
   - Adjust screen brightness
   - Close unnecessary apps
   - Use airplane mode when not needed

2. **Workspace Setup:**
   - Use tray table efficiently
   - Consider laptop stand for better ergonomics
   - Bring external mouse if space allows

3. **Learning Optimization:**
   - Switch between theory and practice
   - Take regular breaks
   - Stay hydrated
   - Use noise-canceling headphones

4. **Code Organization:**
   - Create clear folder structure
   - Comment code thoroughly
   - Use descriptive variable names
   - Save work frequently
